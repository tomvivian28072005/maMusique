Clom

Ta musique, ton player, tes playlists.
Tout reste chez toi. Rien dans le cloud.

Clom est un lecteur de musique personnel et gratuit. Tu installes l'app, tu ajoutes tes morceaux (YouTube, fichiers MP3, import Spotify/Deezer), et tu as ton propre player avec playlists, favoris et covers. Disponible sur PC et Android.

Telecharger pour Windows Windows 10/11 · ~160 Mo Telecharger pour Android Android 8+ · ~15 Mo · APK

Comment ca marche ?

L'experience utilisateur en bref.

💻 Sur PC

Tu installes Clom, ca lance un serveur local et l'app s'ouvre dans ton navigateur. Tu cherches un morceau par titre/artiste, Clom le telecharge depuis YouTube en MP3. Tu organises tes playlists, tes covers, tes favoris. Tout est stocke sur ton disque dur.

📱 Sur telephone

L'app Android se synchronise avec ton PC via Wi-Fi. Tes morceaux, playlists et covers sont copies sur le telephone. Ensuite tu ecoutes hors ligne, sans internet. Notification avec controles play/pause/next.

🎵 Player complet

Lecture, shuffle, repeat, file d'attente, volume par morceau, paroles synchronisees, egaliseur, balance stereo, trim (couper debut/fin), covers personnalisees avec zoom/decalage.

🔒 100% prive

Pas de compte, pas d'abonnement, pas de tracking, pas de serveur distant. Tes donnees restent sur tes appareils. Le code source est ouvert et verifiable sur GitHub.

Installation rapide

Trois etapes et c'est pret.

1

Telecharge et installe

Clique sur le bouton de telechargement ci-dessus. Sur PC, lance l'installeur. Sur Android, installe l'APK (active "Sources inconnues" dans les parametres).

2

Ajoute tes morceaux

Cherche par titre/artiste, colle un lien YouTube, ou importe ta bibliotheque Deezer/Spotify via CSV. Le morceau est telecharge en quelques secondes.

3

Synchronise sur mobile

Connecte ton telephone au meme Wi-Fi que ton PC. Scanne le QR code dans les parametres, et tous tes morceaux sont copies sur le telephone pour l'ecoute hors ligne.

Pour les developpeurs

Le code source est ouvert. Contribue ou fork le projet.

Lancer en mode developpement

# Clone le repo
git clone https://github.com/tomvivian28072005/maMusique.git
cd maMusique

# Cree un venv Python et installe les dependances
python -m venv venv
./venv/Scripts/pip install -r requirements.txt

# Lance le serveur de dev
./venv/Scripts/python -m uvicorn main:app --host 127.0.0.1 --port 9000 --reload

# L'app s'ouvre sur http://localhost:9000

Architecture : le backend est une API FastAPI (Python) qui sert un frontend vanilla JS (un seul fichier index.html de ~10 000 lignes). La base de donnees est SQLite via SQLAlchemy. Le telechargement utilise yt-dlp + ffmpeg. L'app Android est un wrapper Capacitor avec SQLite local.
