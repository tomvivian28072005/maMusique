Comment ca marche

Un lecteur de musique qui tourne sur tes appareils, sans cloud.

Sur PC

Tu installes Clom, ca lance un serveur local et l'app s'ouvre dans ton navigateur. Tu cherches un morceau, Clom le telecharge depuis YouTube en MP3. Tout est stocke sur ton disque.

Sur telephone

L'app Android se synchronise avec ton PC via Wi-Fi. Tes morceaux, playlists et covers sont copies sur le telephone pour l'ecoute hors ligne.

Player complet

Shuffle, repeat, file d'attente, volume par morceau, paroles synchronisees, egaliseur, balance stereo, trim, covers personnalisees.

100% prive

Pas de compte, pas d'abonnement, pas de tracking. Tes donnees restent sur tes appareils. Le code source est ouvert sur GitHub.

Installation

1

Telecharge et installe

Sur PC, lance l'installeur. Sur Android, installe l'APK (active "Sources inconnues").

2

Ajoute tes morceaux

Cherche par titre/artiste, colle un lien YouTube, ou importe depuis Deezer/Spotify.

3

Synchronise sur mobile

Meme Wi-Fi, scanne le QR code, tout est copie pour l'ecoute hors ligne.

Pour les developpeurs

Code source ouvert sous licence AGPL v3.

Lancer en local

# Clone le repo
git clone https://github.com/tomvivian28072005/maMusique.git
cd maMusique

# Installe les dependances
python -m venv venv
./venv/Scripts/pip install -r requirements.txt

# Lance le serveur
./venv/Scripts/python -m uvicorn main:app --host 127.0.0.1 --port 9000 --reload

Stack : API FastAPI (Python) + frontend vanilla JS (un seul index.html). Base SQLite via SQLAlchemy. Telechargement via yt-dlp + ffmpeg. App Android via Capacitor avec SQLite local.
